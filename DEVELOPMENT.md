# Development

## Environment

Use Node.js 22.13+ (Node 24 is suitable) and npm. For Android local builds, install Android Studio with a current Android SDK and configure `ANDROID_HOME`/`ANDROID_SDK_ROOT`; attach an emulator or device. iOS builds require macOS and Xcode. The Expo managed workflow and config plugins are used; native projects are generated by Expo when a local native build is requested.

## Environment variables

Copy `.env.example` to `.env`. Set `EXPO_PUBLIC_SUPABASE_URL` and `EXPO_PUBLIC_SUPABASE_ANON_KEY` for account services. Never use the Supabase service-role key in a mobile client. `EXPO_PUBLIC_TMDB_API_KEY` is reserved for a later phase and currently unused. Public Expo variables are bundled into the application and are not suitable for secrets.

## Common commands

```sh
npm install
npm start
npm run android
npm run ios
npm run typecheck
npm run lint
npm test
npm run format:check
```

The Android/iOS commands require their respective native toolchains; `npm start` launches the Expo development server. `npm test` runs the Jest Expo preset suite.

## Data and guest mode

SQLite initializes on app startup before routes render. Guest session metadata is persisted separately from future collection data. Add schema changes as a new numbered migration; do not edit a migration after it has shipped. Keep SQL in data-layer code and preserve guest data when adding account migration.
